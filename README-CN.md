# 用 Claude Project 打造你的专属 AI 导师：大学课程学习作战手册

## 📋 本节目标

学完这篇教程，你会知道如何从零开始，把一门大学课程的所有资料整合进一个 Claude Project，搭建出一个懂你、懂教材、懂作业需求的专属 AI 导师，并建立起一套可以持续维护、越用越好用的学习机制。

## 🎯 为什么要学这个？

想象这样一个场景：你在学线性代数，凌晨 2 点卡在一道题上，教授没法联系，同学也都睡了。你盯着课本，完全不知道下一步该怎么走。

现在换一个场景：同样凌晨 2 点，同样的题，但你打开了一个专门为这门课搭建的 Claude Project。这个 AI 已经读过你整本教材，知道你作业的具体要求，记得你上次对话结束时还没搞清楚的概念，而且能根据你的理解水平调整它解释的方式和深度。你只需要说一句话："这道题我哪里想错了？"

第二个场景，不是幻想。这篇教程要教你的，就是怎么把它搭建出来。

更重要的是，这套方法不只能用在线性代数上。理工科的公式推导、计算机科学的编程作业、法律的案例阅读、财务分析、文学文本细读——只要是大学课程，底层逻辑完全一样。你学会这个思路，就学会了一种可以用在任何科目上的学习方法。

---

## 📖 整套方法：三个阶段，一次搭建，持续受益

### 第一阶段：把教材"喂给"AI

第一个挑战，也是很多人从来没想到的挑战，是教材的大小问题。一本大学教材动辄七八百页，直接上传到 Knowledge Base 会超出文件大小限制。所以在上传之前，你需要先把它"切小"。

以《Linear Algebra and Its Applications, 5th Edition》为例——你可以直接从[这个链接](https://broman.dev/download/Linear%20Algebra%20and%20its%20Applications%205th%20Edition.pdf)下载这本书。它有将近 600 页，不能直接整本上传，但按章节拆分之后，每个部分大概 60 到 100 页，就完全在上传限制之内了。

**拆分教材** 这件事，不同的人有不同的顺手工具。如果你用 Mac，系统自带的 **Preview** 就能搞定：打开 PDF 后，在 View 菜单里切换到 Thumbnails 视图，你会在左侧看到所有页面的缩略图。按住 Shift 键点击选中你要提取的那段页面，然后把它们拖出来，或者用 File → Export as PDF，就能把这几页另存为一个独立的文件。如果你习惯用在线工具，ilovepdf.com 有专门的 "Split PDF" 功能，按页码范围切割，简单直接。甚至你可以把这个需求直接告诉 Claude，让它帮你写一个自动化脚本——这本身也是一次练习 AI 使用的机会。

拆分完之后，如果单个文件还是偏大，可以再做一步**压缩**。同样在 ilovepdf.com 或者 smallpdf.com 上都有压缩功能，通常能把文件体积缩小 70% 到 90%，而文字内容几乎不受影响。

把这些拆好压好的文件，逐一上传到你 Claude Project 右侧 Files 区域的 **"+"** 号按钮。上传完成后，这个 Project 里所有的对话，Claude 都能够读取和引用这些教材内容了。

### 第二阶段：构建完整的课程上下文

教材只是你这门课的基础材料之一。一门真实的课程还有很多其他资料：教授发的 lecture notes、参考网页、作业描述、往年例题。这一阶段要把这些东西也整合进来，并且让 AI 知道如何有效地使用它们。

第一件事是**整理文件名**。在上传之前，花几分钟把所有资料的文件名整理清楚，用简洁、能看出内容的英文命名，比如 `lecture-01-intro.pdf`、`hw-1-description.pdf`、`reference-eigenvalues.pdf`。这一步看起来细碎，但文件名清晰，是之后 AI 能精准找到对应资料的前提。把整理好的文件和已经上传的教材文件，全部放进同一个 Project 的 Files 区域。

上传完之后，做第二件事：**创建资料索引**。打开一个新对话，把所有文件名列出来发给 Claude，让它帮你生成一个简短的索引文档——每个文件名后面跟两三句话的描述，说明这个文件是什么、大概包含哪些内容。让 Claude 用 Artifact 格式生成这个索引，然后点击 Artifact 右上角的 **"Add to Project"**，把它存进 Knowledge Base。

这个索引文件的作用，会在你写 Instructions 的时候变得很清楚——你可以告诉 AI "这里有一个索引，你需要哪份资料就去查索引，然后再去读对应的文件"，这样 AI 就能按需调取资料，而不是每次都试图把所有文件全部读一遍。

第三件事，也是这个阶段最关键的：**写 Instructions 和需求目标文档**。

**Instructions** 是你写在 Project 右侧 Instructions 区域的系统提示词，它定义了这个 AI 在这个 Project 里的角色和行为方式。你可以直接把你的需求发给 Claude，让它帮你起草一份，然后根据你的情况修改。一份好的 Instructions 大概应该包含这几层意思：这个 AI 是这门课的学习导师，目标是帮你真正理解内化，而不是提供答案；它应该根据你提问时的表达方式判断你的理解水平，用对应的深度来解释；它知道 Knowledge Base 里有哪些资料（通过索引），以及每次对话开始时要先读取 `progress.md` 了解你的学习进度。最后这一条，我们会在第三阶段详细说。

**需求目标文档** 是另一个重要文件，专门用来存放当前作业的相关信息。它不是把教授给的作业题抄一遍，而是你和 Claude 一起消化作业要求之后，用你自己的语言写的一份理解文档——说明这个作业实际上要做什么、涉及到哪些知识点、相关文件有哪些、你认为的关键难点在哪里。把作业描述发给 Claude，告诉它你希望生成这样一份文档，用 Artifact 生成后同样 Add to Project。

### 第三阶段：动态学习与进度管理

知识环境搭好了，学习才真正开始。这个阶段的核心机制，是维护一个叫做 `progress.md` 的文件。

`progress.md` 是一份存在 Knowledge Base 里的 Markdown 文档，用来记录你的学习状态：你现在学到了哪个章节、哪些概念已经搞清楚了、还有哪些疑问悬而未决、上次对话结束时停在什么地方。它存在的意义是给 AI 提供跨对话的记忆——因为每次你开启一个新对话，AI 默认不知道你上次聊了什么，但如果你告诉它"每次开始先读 `progress.md`"，它就能立刻接上你上次的状态，而不需要你重新解释背景。

你需要在 Instructions 里加上这两条规则：每次对话开始时，主动读取 `progress.md`，了解当前的学习进度和上次未解决的问题；每次你说"今天到这里了"或"结束学习"时，生成一份更新后的 `progress.md`（用 Artifact 格式），记录今天学到的内容、你的理解程度、以及还不清楚的地方，并提醒你把它 Add to Project 替换旧版本。

实际的学习对话流程就很自然了。你打开 Project，开启新对话，说一句"继续学 *Linear Algebra and Its Applications*，从第三章的矩阵乘法开始"。Claude 读取 progress.md，知道你上次学到哪里，然后就开始教。你提问、它解释、你觉得还是不懂、它换个角度用另一个例子说、你突然想通了——这种密集的互动反馈，是任何教科书和网课都给不了的体验。

学习过程中，每当你觉得某个概念真正想清楚了，可以让 Claude 帮你把这个理解写成一个 Artifact 笔记，用你自己的语言、你在对话里举过的例子。把这个笔记 Add to Project。一个学期下来，你的 Knowledge Base 里不只有教授的教材，还会有越来越多属于你自己的学习笔记，每一份都是你真实理解的凝结。

## 👨‍🏫 导师寄语：学习的本质没有变，变的是速度和深度

搭完这套系统，你可能会问一个很直接的问题：这和直接让 AI 帮我写作业，到底有什么区别？

我想认真回答这个问题，因为这个区别非常重要。

当你真正理解了矩阵乘法，你可以做 100 道不同形式的练习题，每道题你都能判断自己有没有做对。当你没理解、只是让 AI 替你写了，你的大脑里其实什么都没有发生——AI 理解了，不是你理解了。这套方法的设计逻辑是：AI 负责解释、举例、提问、纠错；你负责理解、判断、表达。作业是展示你理解了多少的舞台，而不是你要从 AI 那里"拿"的东西。

但我想分享给你的不只是这个道理，因为你可能早就听过"不能让 AI 代替你思考"这句话。我想说的是另一件事：**这套方法让学习本身变成了一种全然不同的体验**。

传统的学习方式是这样的：你看书，看不懂某个推导，去翻旁边的注解，还是不懂，搜 YouTube 视频，找了半小时发现没有恰好讲到你卡住的那个点，然后只好硬背下来，考试的时候大概记得，考完之后全忘了。这个过程里，反馈是稀缺的，挫折是廉价的。

新的方式是：遇到不懂的地方，直接问。AI 知道你在学哪个章节，知道你的基础是什么水平，知道你上次在哪里卡住过，它给的解释不是面向所有人的标准答案，而是专门根据你当前的状态设计的。这种密度的个性化反馈，在没有 AI 的时代，只有付得起家教费用的学生才能享有。

最后，我想告诉你一件关于这个时代的事。在过去，学习速度受制于两个瓶颈：第一，你能接触到多好的老师；第二，你有多少时间坐在图书馆里主动钻研。第一个瓶颈，现在基本上消失了——你现在拥有的这个 AI，知识储量比任何一位教授都广，耐心是无限的，而且 24 小时在线。第二个瓶颈还在，但每一分钟的学习效率大幅提升了。

剩下来真正稀缺的资源，是你的判断力——你判断 AI 的解释是否真的说清楚了，你判断自己有没有真正理解，你判断作业的方向是否走偏。这个判断力，是 AI 给不了你的，也是这套方法论最终想要保护和培养的东西。

## 💡 关键要点总结

这套方法的核心不是技术，而是一种新的学习工作流。你把教材和资料整理好、上传好，是在为 AI 创造有效工作的条件；你写好 Instructions，是在定义这个 AI 导师的工作方式；你维护 progress.md，是在让 AI 具备跨对话的记忆；你把自己的理解写成 Artifact 笔记，是在把 AI 帮你产生的思考结晶保存下来，成为真正属于你的东西。

搭建的成本是一次性的，收益是整个学期的。
